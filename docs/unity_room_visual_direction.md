## 1. 目的

ニアの部屋を、単なる「配信背景」ではなく、**ニアがそこにいると感じられる3D空間**として設計する。

このメモは主に以下を固定するためのもの:

- Unity を使うかどうか
- 配信時の画面レイアウト
- ニア本体の基本姿勢
- Pip の見た目と距離感
- 初期段階で必要なモーションの範囲

---

## 2. 基本方針

### 2.1 Unity を使う

3D の部屋を長期的に育てる前提なら、Unity を採用する。

理由:

- カメラ、ライト、空間演出がやりやすい
- アニメーション、Blend Tree、IK を後から伸ばしやすい
- Pip / 部屋 / motion contract をひとつの renderer で扱いやすい
- 将来的にゲーム寄りの空間へ拡張しやすい

補足:

- Web でも 2D / 軽量 3D は可能
- ただし「部屋を存在の器として育てる」方針には Unity が合う

---

## 3. 初期レイアウト方針

### 3.1 採用案: `Window`

ゲーム画面を「部屋の中の大きな窓」として扱う。

構成:

- 正面の壁に大きな発光する窓スクリーン
- ゲーム画面はその窓の中に表示
- コメントは窓の横の細い透過パネル
- ニアは窓の近くに座る
- Pip はニアの近く、床・クッション・窓辺のいずれかにいる

### 3.2 この案を採る理由

- ゲーム画面がモニターではなく、部屋の一部として存在できる
- OBS 風オーバーレイを減らし、配信UIを空間に溶かせる
- ニアの「部屋らしさ」を保ったまま、配信としての見やすさも確保できる

### 3.3 UI の扱い

- コメントは細い縦帯として出す
- 最新数件のみ表示し、常に画面を埋めない
- 配信タイトルや状態は部屋内の小物・プレート・光で表現する
- 画面全体への平面的な UI ベタ載せは避ける

## 4. ニア本体の基本姿勢

### 4.1 基本は `座り`

初期実装では、ニアは座っている状態をベースにする。

理由:

- 実装難易度が大きく下がる
- 歩行や足接地の問題を減らせる
- 配信画面として安定する
- ニアの静かな存在感と相性がいい

### 4.2 想定姿勢

候補:

- クッションに座る
- ベッド端に腰掛ける
- 低い椅子やソファに座る

優先:

- 画像のような「床＋クッション」系
- 窓の方へ体を向けやすい姿勢

### 4.3 初期モーションセット

最小セット:

- `seated_idle`
- `seated_listening`
- `seated_thinking`
- `seated_speaking`
- `seated_soft_shift`

追加候補:

- `stand_transition`
- `standing_small_motion`
- `sit_back`

方針:

- 基本は座り
- たまに立って軽く体を動かす程度に留める

## 5. Pip の見た目方針

### 5.1 方向性

Pip は「かわいいマスコット」ではなく、**静かな companion** として見せる。

望ましい特徴:

- 小さい
- 幾何学的
- 発光する
- 少し異質だが冷たすぎない
- ニアの近くにいても主役を奪わない

### 5.2 今回の参考方向

良い方向として確認できた要素:

- 低ポリ / 幾何学的な輪郭
- 透過感または光の芯
- 白〜青系の静かな発光
- 小動物らしいサイズ感

### 5.3 避けたい方向

- マスコット的すぎる表情
- 派手なキャラ性
- ネオン玩具っぽい強い光
- ニアより目立つサイズ・彩度

---

## 6. Pip との接触

### 6.1 `なでる` は入れる

初期段階から実装候補として持つ。

最初の実装はシンプルでよい:

- ニアの手が少し伸びる
- Pip が寄る
- Pip が頭を預ける / 少し目を閉じる

### 6.2 実装方針

段階:

1. 専用アニメ 1 本 + Pip の反応
2. 条件付き発火
3. 後で IK を追加

発火条件の例:

- ニアが座っている
- Pip が近くにいる
- 強い会話状態ではない
- cooldown 済み

### 6.3 注意

- いつでも撫でられる状態にはしない
- Bond 値を直接見せず、内部条件としてだけ使う

---

## 7. モーション設計の考え方

### 7.1 原則

動きは演出ではなく、**状態の結果**として出す。

### 7.2 役割分担

Unity ローカル:

- 呼吸
- まばたき
- 微小な姿勢揺れ
- idle の小さな変化

backend 由来:

- `conversation_state`
- `motion_event`
- `runtime_facts`
- `atmosphere`

### 7.3 初期段階でやらないこと

- いきなり全身生成AIモーションを目指す
- 歩き回りを主軸にする
- 内部メトリクスへ直接反応する誇張演技を入れる

---

## 8. 実装順

1. Unity に部屋の基本空間を作る
2. `Window` レイアウトを置く
3. ニアを座り状態で配置する
4. Pip を配置する
5. `seated_idle / listening / thinking / speaking` をつなぐ
6. ゲーム窓とコメント帯を接続する
7. Pip の近接・睡眠・視線反応を入れる
8. `なでる` を追加する
9. たまに立つモーションを追加する

---

## 9. 一言でまとめると

**Unity で、窓型スクリーンのある部屋に、座っているニアと小さなPipがいる構成から始める。**

動きは静かに、存在感は強く、配信UIは空間に溶かす。
