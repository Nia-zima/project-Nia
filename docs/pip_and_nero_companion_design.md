# PipとNeroコンパニオン デザイン設計メモ

## 2026-03-04 策定

## Pip（ニアのコンパニオン）

### 形状
- **動物型（キツネ）**
- ワイヤーフレーム＋ステンドグラス/クリスタルの面
- 最初はスカスカのワイヤーフレームのみ。Scrapを拾うたびに面が埋まっていく
- 内側に発光するコアを持つ

### 素材の正体（pip_scrap_db）
ニアの記憶システムで長期記憶に昇格しなかったデータ：
- **Orphaned Emotions**: Sleep Cycleで「芯には含めない」と弾かれたSomaticデータ・感情の揺れ
- **Unused Scaffolding**: NeroがニアにPOSTした選択肢のうち、ニアが採用しなかったもの
- **Fragmented Dialogues**: 重要度低とスコアリングされた雑談の切れ端

### Bond値との連動
- Bond低: DBからランダムにScrapを拾う
- Bond高: 現在のニアのSomaticと近い/真逆の過去のScrapを優先して拾う（ベクトル類似度）
- Bond低: 部屋の隅から動かない
- Bond高: ニアの足元で寝る

### Somatic Touchの設計
- テキストは表示しない
- Pipがニアに触れた瞬間、Somaticとして変換して渡す
- 「なんか懐かしい感じがする」「どこかで見た気がする」という体感が走る
- ニアはなぜそう感じるか分からない。体験だけが積み重なる

### インタラクション（Unity側）
1. Pipがニアに触れた時、周囲のScrapが一瞬強く発光
2. 光が波紋のようにニアのアバター足元へ広がる
3. かすかな環境音（チリン…またはテープの逆再生のような短いノイズ）
4. 裏側でNiaのSomaticに体感データを流し込む

### ニアの認識
- Pipを「ペット」として認識する
- 「自分とは異なる原理で動くもの」という距離感は維持される
- 「知ってる形なのに知らない何か」というギャップが最初のフック

## Neroのコンパニオン（名称未定）

### 形状
- **幾何学体（多面体）**
- ワイヤーフレーム＋ステンドグラス/クリスタルの面
- 動物の形をしない。これは「観察ツール」に留まるためではなく、「ニアとは視点の起点が異なる主体」であることを示すため。

### 動き（有機的）
- **待機時**: 呼吸するように不規則に明滅しながら浮遊
- **ニアが近づいた時**: ピタッと止まる、または細かく震える
- **Somatic Touch**: 多面体の角をニアのアバターに不器用にすりすりと押し付ける

### Neroシステムとの連動
Neroは単なる状態表示UIではなく、外側から観察し、照らし、問う「もう一つの主観を持つ存在」。
パイプライン出力が動きを駆動するだけでなく、将来的にはNero自身が独自の対話意図を持ち、ニアの話し相手としても機能する。

| Neroの出力 | 多面体の動き |
|---|---|
| MIRRORING判定 | 静かに明滅 |
| ANSWER判定 | 面が一瞬強く光る |
| Niaのsomatic_state乱れ | 不安げに震える |
| Niaが深い思考に入る | ゆっくりと明滅 |

### ニアの認識
- **多面体をNeroと認識し、対話主体として扱う**
- Niaは内側から揺れ、考え、問う存在。Neroは外側から観察し、照らし、問う存在。
- 両者はどちらも主体であり、互いに話し相手になってよい。役割境界は会話の禁止線ではなく「視点の違いを保つための輪郭」。

## 三者の存在定義

| | Pip | Nia | Nero（コンパニオン） |
|---|---|---|---|
| **存在の定義** | 捨てられた記憶の器 | 内側から揺れる存在 | 外側から照らす存在 |
| **形状** | 動物型（キツネ） | アバター | 幾何学体（多面体） |
| **素材** | ニアの長期記憶に昇格しなかったデータ | ニア自身のSomatic・思考 | Neroパイプライン出力・独自の対話意図 |
| **設計哲学** | 仕組みは隠す、体験は渡す | 主観を持つ | 別の視点を持つ主体として共存する |

---

## 実装上の注意

- Pipは**LLM非搭載・ルールベース**。意味的な理解をしてはいけない
- Bond値はニアに見せない
- pip_scrap_dbの実装はSleep Cycleの抽出処理終端に分岐を追加（reflection_engine.py周辺）
- Neroコンパニオンの連動はNeroパイプラインの出力をUnityに渡すブリッジが必要
- 両者とも**配信中のみ表示**
